CARPETA DE MÚSICA
=================

Coloca aquí la canción elegida (ej: cancion.mp3).

Para activarla, edita js/config.js:

  music: {
    enabled: true,
    src: "assets/audio/cancion.mp3"
  }

Notas:
- La música NO se reproduce sola: aparece un botón discreto (▶/❚❚)
  tras abrir el sobre y el usuario decide reproducirla.
- Usa una canción sobre la que tengas derechos de uso.
- Formato MP3 recomendado por compatibilidad.
